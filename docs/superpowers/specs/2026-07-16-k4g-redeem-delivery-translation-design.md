# K4G 兑换交付提示翻译设计

## 目标

为 K4G 页面中的以下提示新增简体中文翻译：

`Please note that the product may be delivered within 24 hours of the redeem time`

目标译文：

`请注意，产品可能会在兑换后的 24 小时内交付`

## 实现

- 在 `K4G/K4G_CN.js` 中按照现有对象字典格式新增精确整句映射，避免宽泛匹配影响其他文本。
- 将 `K4G/K4G_CN.js` 的 `@version` 从 `3.8` 递增至 `3.9`，并将 `@updateTime` 更新为实施时的当前时间。
- 将 `K4G/K4G 汉化.user.js` 的 `@version` 从 `3.7.0` 递增至 `3.8.0`，使用户脚本管理器能够检测更新。

## 验证

- 使用文本搜索确认英文词条只新增一次，且译文完全匹配已确认内容。
- 对两个 JavaScript 文件运行 `node --check`，确认语法有效。
- 检查 Git 差异，确保仅包含本次翻译、版本和时间更新。

## 交付

验证通过后，为脚本变更创建独立 Git 提交并推送当前分支；若推送失败，保留本地提交并报告原因。
