# AGENTS.md Git 工作流设计

## 目标

在仓库根目录新增 `AGENTS.md`，记录 K4G 翻译词典的版本维护规范，以及脚本修改完成后的自动提交与推送规则。

## 规则

- 每次新增或修改 K4G 翻译词条后，同步更新 `K4G_CN.js` 头部的 `@version` 与 `@updateTime`。
- `@version` 按小版本递增，例如 `2.0`、`2.1`、`2.2`。
- `@updateTime` 使用修改时的当前时间，格式为 `YYYY/M/D HH:mm:ss`。
- 同步更新 `K4G 汉化.user.js` 的 `@version`，确保浏览器扩展能够检测更新。
- 每完成一个脚本并确认相关测试通过后，自动创建一次独立 Git 提交，无需用户再次提醒。
- 测试未通过时不得提交或推送。
- 提交成功后自动推送当前分支到其对应的远端分支；推送失败时保留本地提交并明确报告失败原因。

## 验证

- 检查 `AGENTS.md` 包含全部版本规范与 Git 工作流规则。
- 检查工作区差异，确保没有覆盖用户已有修改。
- 运行与本次脚本改动相关的测试和语法检查。
- 仅在验证通过后提交并推送。
