## Release

如果需要从源码构建脚本，可以直接编辑相应的 `.js` 文件。脚本使用纯 JavaScript 编写，无需构建步骤，修改后可直接使用。

```bash
# 克隆仓库
$ git clone https://github.com/shadowxhero/shadow.git
$ cd shadow

# 直接编辑相应的 .js 文件进行修改
```
